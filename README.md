# Revisao de Ciclo META360TDAH

Pagina HTML estatica para coletar percepcoes da familia ao fim do ciclo do META360TDAH e enviar as respostas ao Formspree.

## Publicacao no Netlify

1. Suba este projeto em um repositorio no GitHub.
2. Conecte o repositorio ao Netlify.
3. Deixe o campo "Build command" vazio.
4. Use a raiz do projeto como "Publish directory".
5. Publique o site.

## Observacoes

- O arquivo principal deve permanecer como `index.html`.
- Nao ha backend, banco de dados, cookies, localStorage, build process ou dependencias externas.
- A interface nao mostra score, NPS, cores de classificacao ou mensagem comercial de renovacao.
- Use apenas iniciais ou codigo interno do paciente.
